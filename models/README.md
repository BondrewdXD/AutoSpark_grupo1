# Models

Los **Models** son representaciones de los datos en la base de datos. En el backend, los modelos definen las estructuras de los datos y cómo interactúan con la base de datos. Los modelos representan tablas o colecciones en la base de datos y proporcionan un mecanismo para almacenar, recuperar, actualizar y eliminar datos.

## Funciones principales:
- **Definir estructura de datos**: Los modelos definen las propiedades y la estructura de los datos.
- **Interacción con la base de datos**: Los modelos interactúan directamente con la base de datos utilizando ORMs (Object-Relational Mapping) o consultas SQL directas.
- **Validaciones y reglas de negocio**: Los modelos también pueden incluir validaciones para garantizar que los datos sean correctos antes de ser guardados.
